Video Priority Playback Feature

UML Graph Studio supports automatic prioritized video playback for nodes containing videos (mediaType: "video"):

  • Priority Ordering: If priorities are numbers (e.g. 1, 2, 10), they sort numerically. If priorities are strings (e.g. "P01", "VIP"), they sort using their natural alphabetical sorting values.
  • Sequential Progression: When all videos of the active priority finish (detected via duration/ended events), the system automatically advances to the next priority.
  • Continuous Looping: After the last priority finishes, the sequence cycles back to the first priority.

File Format Overview

A .umlgraph file is a self-contained JSON document containing diagram metadata, canvas view settings, nodes, groups, and connections.

{
  "diagramId": "diag_example",
  "diagramName": "System Architecture",
  "canvas": { "zoom": 1, "panX": 0, "panY": 0 },
  "nodes": [
    {
      "id": "node_1",
      "x": 60, "y": 60, "w": 260, "h": 160,
      "title": "API Gateway",
      "desc": "Authentication and rate limiting.",
      "priority": "1",
      "shape": "rounded",
      "color": "#1e293b",
      "borderColor": "#3b82f6"
    }
  ],
  "connections": [],
  "updatedAt": 1727300000000
}
